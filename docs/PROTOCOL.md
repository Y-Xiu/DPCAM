# SolDef_AI 两任务实验协议

本协议对应 `two_task_v1` 与 `two_task_comparison_v1`。目标是在固定数据和选模规则下评估 ConvNeXt-Base + DPCAM 的实际表现；有效性由实验结果决定。

## 数据与任务

数据来源：[SolDef_AI 来源论文](https://www.mdpi.com/2504-4494/8/3/117)，DOI `10.3390/jmmp8030117`。来源中的图像总数、元件数与焊点数是不同统计单位，不能将 460 个焊点写成 460 张带标注任务图像。当前实验使用可核对的 228 张 Task 1 与 200 张 Task 2 带标注原图，分别重建多类语义掩码。

| 项目 | Task 1：元件放置状态 | Task 2：焊点状态 |
|---|---|---|
| 配置数据集名 | `soldef_task1` | `soldef` |
| 视角 | 俯视 | 45° |
| 类别顺序 | background, good, no_good | background, good, exc_solder, poor_solder, spike |
| 带标注原图 | 228 | 200 |
| 原图 train / val / test | 159 / 34 / 35 | 140 / 30 / 30 |
| 每原图裁剪 | 两个 1440 × 1440 窗口，中心横向偏移 ±100 | 左右两个不重叠 1024 × 1024 窗口 |
| 裁剪 train / val / test | 318 / 68 / 70 | 280 / 60 / 60 |
| 裁剪合计 | 456 | 400 |
| 网络输入 | 512 × 512 | 512 × 512 |

划分种子固定为 42，目标比例 70% / 15% / 15%，训练和验证原图数向下取整，测试接收余数。按来源原图分组进行多标签分层，同一原图的所有裁剪共享 split。检查原图 ID、原图内容哈希及处理图像哈希的跨集合重叠；数据清单记录文件哈希和裁剪坐标。

该划分只保证来源图像不跨集合，尚不能证明物理元件或 PCB 个体在集合之间独立。Task 1 的两个裁剪相互重叠，不是两个独立原始样本。原裁剪审计发现 121 / 456 个 Task 1 裁剪截断部分前景，平均前景保留率约 98.051%；两个裁剪的并集仍有 14 张原图未覆盖全部前景。本协议保留该处理方式用于同条件比较，论文应披露其影响；改变裁剪方式需要建立新协议并重跑受影响的比较。

`data/splits/` 提供划分参考，实际训练使用 `data/processed/<dataset>/manifest.json`。旧裁剪级划分不能与当前原图分组结果混用。准备脚本不会把旧的处理图像直接重分组后冒充新的原图级复现。

## 90 项匹配消融

两个任务 × 九种变体 × 五个训练种子（42、43、44、45、46），共 90 次训练。五个种子使用同一份固定数据划分，**不是五折交叉验证**。

所有变体采用 ConvNeXt-Base 编码器和相同解码器。先在同一随机种子下建立共享编码器、解码器及分割头，再用隔离的随机数状态添加注意力，使共享参数及 BN 缓冲区的初值一致。

| 变体 | 含义 |
|---|---|
| `none` | 无注意力的 ConvNeXt-Base + U-Net 基线 |
| `cbam` | CBAM 对照 |
| `dpcam` | 原乘法 DPCAM，包含 DCA、PA、DSA |
| `no_dca` | 移除动态通道注意力 |
| `no_pa` | 移除位置注意力 |
| `no_dsa` | 移除动态空间注意力 |
| `equal_spatial` | 保留空间卷积分支，将动态分支权重改为等权平均 |
| `residual_cbam` | 独立残差候选：`x + alpha * CBAM(x)` |
| `residual_dpcam` | 独立残差候选：`x + alpha * DPCAM(x)` |

残差系数 `alpha` 从零开始学习。残差候选改变了方法方程，应单独报告，不可与原 DPCAM 合并统计。

## 60 项新增模型比较

两个任务 × 六个模型 × 五个种子，共 60 次训练：

| 模型 | 实现与监督 |
|---|---|
| EMCAD / PVTv2-B2 | 作者编码器与多尺度解码器；保留 15 个输出子集组合的监督 |
| SegMAN-S | 作者编码器及解码器，使用所需 NATTEN / selective scan 算子 |
| MambaVision-T + UPerNet | 作者骨干与分割适配，保留 FCN 辅助头 |
| SegFormer-B2 | MiT-B2 与 SegFormer 分割头 |
| U-Net | 经典 U-Net，从随机初始化训练 |
| DeepLabv3 / ResNet-101 | ResNet-101 编码器与 DeepLabv3 分割头 |

作者实现的来源、版本和本地适配范围见 [第三方说明](THIRD_PARTY.md)。除经典 U-Net 外，配置使用 ImageNet 编码器预训练；分割头随机初始化。上述 MambaVision-T 中的 T 是该对比模型规格，主方法仍为 ConvNeXt-Base。

## 训练、选模与冻结

统一预算：150 轮、batch size 2、FP32、AdamW、初始学习率 `1e-4`、余弦衰减至 `1e-6`、权重衰减 `1e-5`。不依据测试结果调整轮数、种子或模型配置。

原方法消融及 U-Net / DeepLabv3 使用稳定数值实现的 `0.5 Dice + 0.5 Focal`，Focal `alpha=0.25`、`gamma=2`；该实现基于 softmax 后逐类 one-vs-rest 计算。现代模型保留必要的作者监督：EMCAD 为各输出子集的 `0.3 CE + 0.7 Dice` 求和，SegMAN / SegFormer 为 CE，MambaVision 为主头 CE 加 `0.4 ×` 辅助头 CE。因此统一的是数据、训练预算和验证选模规则，不能描述为全部模型使用相同训练损失。

所有模型均以**验证集主输出的稳定 Dice/Focal 损失最低值**选择 `best.pt`。150 轮结束后重新加载该检查点并核对验证指标。配置、运行源码和数据清单受哈希校验；新增对比中的显式权重文件另有大小与 SHA256 校验。ConvNeXt 的 timm 预训练来源记录在运行信息中，但当前未单独锁定下载文件 SHA256，因此不能声称所有初始化文件都已按字节冻结。同一实验批次不能静默更换实现或初始化来源。

60 项对比队列需等待 90 项消融全部完成并通过验证重载。全部 150 项通过后，`comparison_study.finalize` 冻结选中检查点的哈希，随后进行最终测试。最终测试不参与检查点选择；验证汇总与测试汇总分开。该流程描述了预定门控，当前不代表所有门控已经通过。

## 指标与统计

先累积整个评估集合的像素混淆矩阵，再计算逐类指标，不能直接平均各图片的 IoU 代替该定义。

| 表头 | 定义与单位 |
|---|---|
| mIoU (%) | 包含背景的全部类别 IoU 宏平均 × 100 |
| mPA (%) | 包含背景的全部类别召回率宏平均 × 100；不是 overall pixel accuracy |
| Recall_defect (%) | Task 1 为 no_good 召回率；Task 2 为 exc_solder、poor_solder、spike 召回率的宏平均 × 100 |
| F1_macro | 包含背景的逐类 F1 宏平均，范围 0–1；同定义下等于 mDice |
| Parameters (M) | 参数总数 / 1e6，包含辅助头；注明实际构建的模型配置 |
| FLOPs_supported (G) | profiler 支持算子的计数 / 1e9，乘加计 2；不能视为完整模型 FLOPs |
| FPS | 统一输入与设备上的模型前向速度，不含数据加载与后处理 |

空分母类别按零计入宏平均，避免不同运行隐式排除不同类别。前景 mIoU 如需报告，必须注明排除了背景；它不替代主表 mIoU。不要重复列出数学等价的 mDice 与 F1_macro 作为两项独立证据。

多种子结果报告均值 ± **样本标准差**（`ddof=1`），并保留实际完成种子数 `n`。不足五个种子时标注未完成，不能按性能挑选种子。两任务分别计算，三类与五类的宏平均不能直接合并排名。

效率测量计划为同一空闲 RTX 3090、512 × 512、batch size 1、FP32、关闭 TF32，30 次预热和 200 次计时。只有实际通过该测量的结果才能填入 FPS。SSM、NATTEN、融合注意力等算子可能不被 profiler 完整覆盖；完整 FLOPs 应留空或另用经过核验的计数规则，不能用受支持算子总数宣称完整计算量优势。

来源论文中的 Mask R-CNN 实例分割 AP 与上述语义分割指标的任务和聚合方式不同，不能作数值等价比较。
