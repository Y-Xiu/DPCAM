## 数据和解释限制

Task 1 存在裁剪截断前景的情况；两任务只验证了来源图像不跨集合，未证明物理元件或 PCB 个体独立。预训练使用和作者损失存在模型间差异，实验比较应按 [协议](PROTOCOL.md) 披露。部分现代网络的算子缺少完整 FLOPs 计数支持，受支持算子计数不能作为完整网络计算量。

当前代码中的训练轮数、输入尺寸与模型参数是协议设定，不是新一轮实验已成功运行的证据。CPU 检查与静态检查不等于 GPU 检查通过。后续结果必须注明验证集 / 测试集、实际完成种子数及标准差；未完成项保留空值。
